# 生平简介

张雪峰，本名张子彪，出生于黑龙江省齐齐哈尔市富裕县，祖籍山东临清，毕业于郑州大学给排水工程专业。峰学蔚来创始人，生前系江苏省人大代表、苏州峰学蔚来教育科技有限公司法定代表人、苏州研途教育科技有限公司副总裁。2016年凭借《七分钟解读34所985高校》走红网络，此后参加《火星情报局》《演说家》等多档综艺节目，在抖音、微博等平台拥有大量粉丝。他被称为"考研名师"，以犀利的语言风格和对高校招生的独特见解受到广泛关注，其言论也多次引发社会争议。2026年3月24日因心源性猝死在苏州逝世，终年41岁。

# 主要贡献

张雪峰是中国教育咨询领域最具影响力的网络红人之一，他的高考志愿填报和考研指导影响了数百万学生和家长。他创办的峰学蔚来公司致力于教育咨询和研学游业务。他发明了"一种高校招生信息推荐方法和系统"并获得国家专利。作为江苏省人大代表，他积极参与教育领域的公共事务。他将高校招生信息以通俗易懂的方式传递给大众，推动了中国教育信息透明化的进程。
