# 黄大年

![](pics/huang-danian.jpg)

- 姓名：黄大年
- 性别：男
- 国籍：中国
- 出生日期：1958年8月28日
- 去世日期：2017年1月8日
- 去世原因：胆管癌

# 生平简介

黄大年，出生于广西南宁，世界著名地球物理学家、战略科学家。1975年参加工作，1982年获长春地质学院学士学位，1986年获硕士学位，1996年获英国利兹大学博士学位。1997年起在英国剑桥ARKeX航空地球物理公司任高级研究员，成为国际航空地球物理领域的顶尖科学家。2009年放弃海外优越生活，回国到吉林大学任教，担任新兴交叉学科学部首任部长。他带领团队开展深部探测关键仪器装备研发，取得多项重大突破。2017年1月8日因胆管癌在长春逝世，年仅58岁。

# 主要贡献

黄大年是"千人计划"首批入选专家，致力于推动中国深地探测事业发展。他带领团队完成了高精度航空重力测量系统等多项"卡脖子"技术攻关，将中国深部探测能力提升至国际领先水平。他主持的"深部探测关键仪器装备研制与实验"项目取得重大成果，填补了多项国内技术空白。他培养了大批优秀人才，推动了地球物理学学科建设。2017年习近平总书记作出向黄大年学习的重要指示，他被追授"时代楷模""全国优秀共产党员"等荣誉称号。
