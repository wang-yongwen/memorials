# 生平简介

余光中，祖籍福建永春，出生于江苏南京，中国当代著名诗人、散文家、学者、翻译家。1949年随父母迁至香港，次年赴台湾，就读于台湾大学外文系。1959年获美国爱荷华大学艺术硕士学位。曾任台湾中山大学文学院院长、台湾师范大学教授等职。他一生从事诗歌、散文、评论、翻译创作，是当代文坛巨匠。1972年创作《乡愁》，表达对祖国大陆的深切思念。2017年12月14日在高雄逝世，享年90岁。

# 主要贡献

余光中被誉为"乡愁诗人"，《乡愁》以邮票、船票、坟墓、海峡等意象，抒发了对故乡和亲人的思念，成为华人世界家喻户晓的经典诗作。他的诗歌融合传统与现代，兼具古典韵味与现代意识。他著有《白玉苦瓜》《记忆像铁轨一样长》等数十部作品集，翻译了《梵高传》等多部作品。他致力于推动中华文化传承，主张"蓝墨水的上游是汨罗江"，强调中华文化的根源性。他的作品被广泛收录于两岸三地的教材中。
