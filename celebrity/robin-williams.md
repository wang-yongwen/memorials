# 罗宾·威廉姆斯（Robin Williams）

- 姓名：罗宾·威廉姆斯（Robin Williams）
- 性别：男
- 国籍：美国
- 出生日期：1951年7月21日
- 去世日期：2014年8月11日
- 去世原因：自杀（患有路易体痴呆）

# 生平简介

罗宾·威廉姆斯，美国著名喜剧演员、影视演员，毕业于茱莉亚学院。2014年8月11日在加利福尼亚州蒂伯龙去世，享年63岁。

# 主要贡献

主演《死亡诗社》《心灵捕手》《窈窕奶爸》等经典，凭《心灵捕手》获奥斯卡最佳男配角，被誉为一代喜剧天才。
