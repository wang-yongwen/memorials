# 生平简介

黑泽明（Akira Kurosawa），出生于日本东京，日本著名电影导演。1943年开始执导电影，1950年执导《罗生门》，获得威尼斯国际电影节金狮奖。他的代表作包括《七武士》《乱》《影武者》等。1990年获得奥斯卡终身成就奖。1998年9月6日在东京逝世，享年88岁。

# 主要贡献

黑泽明是日本电影的代表人物，被誉为"电影天皇"。他的作品以宏大的叙事和深刻的主题著称，对世界电影产生了深远影响。他获得过多个国际电影奖项。
