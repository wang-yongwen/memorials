# 生平简介

英国计算机科学家，爱丁堡大学计算机科学基础实验室（LFCS）联合创始人。在函数式编程语言和形式化方法领域做出了开创性贡献。与Robin Popplestone共同发明了POP-2编程语言，后开发了Hope语言。

# 主要贡献

爱丁堡大学LFCS实验室联合创始人，POP-2语言共同发明人，Hope函数式编程语言开发者。在程序推理和形式化验证方面的研究深刻影响了函数式编程的发展。2009年获ACM SIGPLAN成就奖。
