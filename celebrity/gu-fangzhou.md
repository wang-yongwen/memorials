# 生平简介

顾方舟，浙江宁波人，出生于上海，中国共产党党员，医学科学家、病毒学专家，中国医学科学院北京协和医学院原院长、一级教授。1944年至1950年就读于北京大学医学院医学系，1951年至1955年留学苏联医学科学院病毒学研究所，获医学副博士学位。1957年开始研究脊髓灰质炎。1958年在中国首次分离出脊灰病毒，1960年成功研制出首批脊髓灰质炎活疫苗，1962年牵头研制成功糖丸减毒活疫苗。1984年至1992年任北京协和医学院院长。2019年1月2日在北京逝世，享年92岁。被称为“中国脊髓灰质炎疫苗之父”、“糖丸爷爷”。

# 主要贡献

顾方舟将毕生精力投入到消灭脊髓灰质炎的战斗中，对脊髓灰质炎的预防及控制的研究长达42年，是中国组织培养口服活疫苗开拓者之一。他研制的糖丸疫苗使数十万名儿童免于致残，中国“脊灰”年平均发病率从十万分之4.06下降到十万分之0.046。2000年世界卫生组织证实中国本土“脊灰”野病毒的传播已被阻断，成为无“脊灰”国家。他还积极推动中国免疫学的发展，推动成立了中国免疫学会并担任首任理事长。2019年9月被授予“人民科学家”国家荣誉称号，被评为“感动中国2019年度人物”。他“一生一事，一丸一世，一粒糖丸，护佑万千儿童。
