# 朱令

![](../pics/zhu-ling.jpg)

- 姓名：朱令
- 性别：女
- 国籍：中国
- 出生日期：1973年11月24日
- 去世日期：2023年12月22日
- 去世原因：脑瘤并发铊中毒后遗症

# 生平简介

本名朱令令，出生于北京。1992年进入清华大学化学系物理化学和仪器分析本科专业学习，曾为清华民乐队队员。1994年11月出现中毒症状，1995年3月再次到北京协和医院就诊，病重进入ICU并陷入两个月的昏迷。同年4月，病症被同学翻译成英文发到互联网紧急求助，一周内收到世界各地1500封回邮，最终确诊为铊中毒。案件以投毒立案调查，但因证据不足至今未破。2004年同学在美国成立"帮助朱令基金会"。2023年11月因脑瘤发作陷入重度昏迷，12月22日在北京离世，年仅50岁。

# 主要贡献

朱令案是中国互联网历史上第一起通过网络求助引发广泛关注的公共事件，推动了社会各界对铊中毒危害和校园安全的重视，以及对中国司法制度和社会正义的持续反思。
