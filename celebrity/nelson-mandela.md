# 曼德拉（Nelson Mandela）

![](../pics/nelson-mandela.jpg)

- 姓名：曼德拉（Nelson Mandela）
- 性别：男
- 国籍：南非
- 出生日期：1918年7月18日
- 去世日期：2013年12月5日
- 去世原因：长期肺部感染后逝世

# 生平简介

纳尔逊·曼德拉，南非政治家，南非首位黑人总统。早年投身反种族隔离斗争，被监禁27年。1990年获释，1994年至1999年任南非总统。2013年12月5日在约翰内斯堡逝世，享年95岁。

# 主要贡献

领导结束南非种族隔离制度，推动民族和解，获1993年诺贝尔和平奖。
