# 费尔南多·科尔巴托

- 姓名：Fernando Corbató（费尔南多·科尔巴托）
- 性别：男
- 国籍：美国
- 出生日期：1926年6月
- 去世日期：2019年7月12日
- 去世原因：自然逝世

# 生平简介

西班牙移民的后裔，1926年6月生于加州奥克兰。高中时二战爆发，提前毕业进入加州大学伯克利分校，不久应征入伍参加海军。1950年获加州理工学院物理学学士学位。麻省理工学院计算机科学与工程系教授，著名的计算机系统专家。

# 主要贡献

领导开发了兼容分时系统（CTSS），这是世界上首个实用的分时操作系统。随后主导Multics项目，其设计思想深刻影响了Unix和现代操作系统的开发。推动了计算机从批处理向交互式使用的革命性转变。1990年获图灵奖。
