# 金庸

# 生平简介

金庸，本名查良镛，浙江海宁人，现代武侠小说作家、新闻家、企业家。1944年考入重庆中央政治大学外交系，后转入东吴大学法学院。1948年移居香港，进入《大公报》工作。1955年开始以"金庸"为笔名创作武侠小说，1959年创办《明报》。一生创作了15部武侠小说，包括《射雕英雄传》《神雕侠侣》《倚天屠龙记》《天龙八部》《笑傲江湖》《鹿鼎记》等经典作品。1972年宣布封笔，之后修订作品并参与香港基本法起草工作。2018年10月30日在香港逝世，享年94岁。

# 主要贡献

金庸是中国武侠小说的一代宗师，被誉为"香港四大才子"之一。他的作品"飞雪连天射白鹿，笑书神侠倚碧鸳"共计14部长篇小说，发行量超过3亿册，被翻译成多种语言，影响了几代读者。他将中国传统文化融入武侠故事，塑造了郭靖、黄蓉、杨过、令狐冲等经典人物形象，提出"侠之大者，为国为民"的价值观。他的作品多次被改编成电视剧、电影、游戏，成为中国流行文化的重要组成部分。他创办的《明报》是香港最有影响力的报纸之一，他还积极参与香港回归事务，担任基本法起草委员会委员。
