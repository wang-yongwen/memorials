# 贝利（Pelé）

![](../pics/pele.jpg)

- 姓名：贝利（Pelé）
- 性别：男
- 国籍：巴西
- 出生日期：1940年10月23日
- 去世日期：2022年12月29日
- 去世原因：结肠癌致多器官功能衰竭

# 生平简介

巴西著名足球运动员，被公认为"球王"。职业生涯打进1281粒进球，为巴西国家队赢得三届世界杯冠军。

# 主要贡献

作为世界足球史上最伟大的球员之一，重新定义了足球运动。1999年被国际奥委会评为"世纪最佳运动员"。
