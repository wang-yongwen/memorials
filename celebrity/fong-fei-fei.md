# 凤飞飞

![](pics/fong-fei-fei.jpg)

- 姓名：凤飞飞
- 性别：女
- 国籍：中国
- 出生日期：1953年8月20日
- 去世日期：2012年1月3日
- 去世原因：肺癌

# 生平简介

凤飞飞，原名林秋鸾，出生于中国台湾桃园县，中国台湾著名歌手、主持人。1971年发行首张专辑《祝你幸福》，开始歌唱生涯。她的代表作包括《掌声响起》《追梦人》《月朦胧鸟朦胧》等。她曾多次获得台湾金曲奖，被誉为"帽子歌后"。她还主持过《我爱彩虹》等综艺节目。2012年1月3日因肺癌在香港逝世，享年58岁。

# 主要贡献

凤飞飞是台湾乐坛的重要人物，她的歌曲深受两岸三地听众喜爱。《掌声响起》成为华语乐坛的经典之作，激励了无数人。她的演唱风格温柔甜美，舞台形象优雅大方。她获得过台湾金曲奖特别贡献奖，是华语乐坛的传奇歌手。
