# 坂本龙一

![](pics/ryuichi-sakamoto.jpg)

- 姓名：坂本龙一
- 性别：男
- 国籍：日本
- 出生日期：1952年1月17日
- 去世日期：2023年3月28日

# 生平简介

日本著名作曲家、钢琴家、歌手。毕业于东京艺术大学。抗癌多年仍坚持音乐创作，奉行"悲观思考，乐观行事"的人生态度。

# 主要贡献

为《末代皇帝》配乐获得奥斯卡最佳原创配乐奖，是第一位获此殊荣的日本人。音乐作品跨越国界，代表作包括《Merry Christmas Mr. Lawrence》等，对全球音乐界产生深远影响。
