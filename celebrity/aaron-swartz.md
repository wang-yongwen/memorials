# Aaron Swartz

![](../pics/aaron-swartz.jpg)

- 姓名：Aaron Swartz（亚伦·斯沃茨）
- 性别：男
- 国籍：美国
- 出生日期：1986年11月8日
- 去世日期：2013年1月11日
- 去世原因：自杀

# 生平简介

出生于美国芝加哥，年少成名的计算机天才。14岁参与编写RSS 1.0规范，后参与开发Creative Commons许可协议。2005年与朋友联合创立社交新闻网站Reddit。设计了web.py Web应用框架。致力于网络信息开放与自由，是数字时代的"罗宾汉"。2011年因从MIT网络下载大量JSTOR学术期刊文章而被联邦检察官起诉，面临最高35年监禁。2013年1月11日在纽约布鲁克林公寓中自杀身亡，年仅26岁。

# 主要贡献

参与制定RSS 1.0规范、Creative Commons许可协议。联合创立Reddit，设计web.py框架。积极倡导网络信息自由与开放获取运动，推动了互联网自由文化的发展。
