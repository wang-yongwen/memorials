# 稻盛和夫

![](pics/inamori-kazuo.jpg)

- 姓名：稻盛和夫
- 性别：男
- 国籍：日本
- 出生日期：1932年1月30日
- 去世日期：2022年8月24日
- 去世原因：自然衰老

# 生平简介

日本著名企业家，京瓷公司和KDDI创始人。，被誉为"经营之圣"。2010年应日本政府请求重整破产的日航公司。

# 主要贡献

创立京瓷公司，开发陶瓷技术应用于电子工业。创立KDDI成为日本第二大电信运营商。提出"阿米巴经营"管理模式，影响全球企业管理。
