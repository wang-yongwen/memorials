# 皮尔·卡丹

![](pics/pierre-cardin.jpg)

- 姓名：皮尔·卡丹
- 性别：男
- 国籍：法国
- 出生日期：1922年7月2日
- 去世日期：2020年12月29日
- 去世原因：自然衰老

# 生平简介

皮尔·卡丹（Pierre Cardin）出生于意大利威尼斯近郊，14岁辍学在裁缝店当学徒，17岁只身前往巴黎闯荡，在迪奥公司学习工作数年。1950年独立开设服装设计公司，提出“时装必须大众化”的口号。1953年举办第一次时装展览，1954年推出气泡裙，1956年推出球形裙。1966年发布无性别宇航服系列，充满未来感。1979年将时尚理念引进中国，成为最早进入中国的国际品牌之一。1983年被授予法兰西荣誉勋章，1991年被任命为联合国教科文组织荣誉大使。皮尔·卡丹的事业不仅限于时装，还扩展到化妆品、餐饮、家具等领域，打造出庞大的“卡丹王国”。

# 主要贡献

皮尔·卡丹是20世纪最具影响力的时装设计师之一，设计理念大胆超前，充满未来感，三次获得法国高级时装界的“金顶针奖”。他最早将高级时装成衣化，让普通大众也能享受到高级时尚。他设计的太空系列、几何图形服装和巨型首饰，影响了几代设计师。1979年第一个把国际时尚品牌带到中国，1985年在北京工人体育馆举办万人时装表演，1988年在天津开设西服生产厂，为中国时尚产业的发展做出了开创性贡献。他热爱太空和高科技，曾穿着宇航服登上时尚杂志封面，被称为“未来世界的设计师”。
