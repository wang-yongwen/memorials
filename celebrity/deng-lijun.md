# 生平简介

邓丽君，出生于中国台湾云林县，中国台湾著名歌手。1967年发行首张专辑，开始歌唱生涯。她的代表作包括《甜蜜蜜》《小城故事》《月亮代表我的心》等。她的歌声甜美动人，深受两岸三地及全球华人喜爱。1995年5月8日因哮喘病在泰国清迈逝世，享年42岁。

# 主要贡献

邓丽君是华语乐坛的传奇歌手，被誉为"华语歌后"。她的歌曲影响了几代人，《甜蜜蜜》等经典歌曲成为华人世界的共同记忆。她获得过台湾金曲奖特别贡献奖等多项荣誉。
