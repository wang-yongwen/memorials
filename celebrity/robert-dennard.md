# Robert Dennard

![](../pics/robert-dennard.jpg)

- 姓名：Robert Dennard（罗伯特·丹纳德）
- 性别：男
- 国籍：美国
- 出生日期：1932年9月5日
- 去世日期：2024年4月23日
- 去世原因：自然逝世

# 生平简介

出生于美国德克萨斯州，1954年和1956年在南方卫理公会大学获得电气工程学士和硕士学位，1958年在卡内基理工学院取得博士学位。同年加入IBM研究院，成为IBM Fellow。在IBM工作超过50年，专注于微电子和半导体技术研究。2024年4月23日逝世，享年91岁。

# 主要贡献

1968年发明了动态随机存取存储器（DRAM），即单晶体管存储单元，成为现代计算机内存的基础技术。提出了著名的"Dennard缩放定律"，指导了半导体行业数十年的发展。1988年获美国国家技术奖章，2009年获IEEE荣誉勋章。
