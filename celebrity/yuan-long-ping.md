# 袁隆平

- 姓名：袁隆平
- 性别：男
- 国籍：中国
- 出生日期：1930年9月7日
- 去世日期：2021年5月22日
- 去世原因：多器官功能衰竭

# 生平简介

江西省九江市德安县人，中国杂交水稻事业的开创者和领导者，被誉为"杂交水稻之父"。曾任国家杂交水稻工程技术研究中心主任、中国工程院院士。

# 主要贡献

成功研发"三系法"杂交水稻、"两系法"杂交水稻，为解决中国乃至世界粮食问题做出巨大贡献。获得"共和国勋章"、联合国科学奖、沃尔夫奖、世界粮食奖等众多荣誉。
