# 傅聪

![](pics/fou-tsong.jpg)

- 姓名：傅聪
- 性别：男
- 国籍：英国
- 出生日期：1934年3月10日
- 去世日期：2020年12月28日

# 生平简介

傅聪出生于上海，是著名翻译家傅雷的长子。三四岁时就展现出对音乐的非凡热爱，七岁半被父亲的挚友雷垣发现极高的音乐天赋，转而学习钢琴。九岁半拜师意大利指挥家、钢琴家梅帕器（李斯特再传弟子），接受良好的音乐教育。1954年赴波兰留学，1955年获第五届肖邦国际钢琴比赛第三名和“玛祖卡”最佳演奏奖，是东方人首次在此赛事获奖。1959年首次在伦敦皇家节日大厅登台，20余年里举办约2400场独奏音乐会，与梅纽因、巴伦博伊姆等国际著名演奏家合作，演出足迹遍及五大洲。1982年任中央音乐学院钢琴系兼职教授，次年获香港大学荣誉博士学位，曾担任肖邦国际钢琴大赛评委。2020年因感染新冠病毒在英国逝世。

# 主要贡献

傅聪被誉为“中国的肖邦”和“钢琴诗人”，是首位在国际钢琴大赛中获奖的中国钢琴家。美国《时代周刊》在60年代誉其为“当今最伟大的中国音乐家”。他对肖邦作品的演绎举世公认，被誉为“肖邦的最佳诠释者之一”，波兰观众称赞他“只有古老的文明，才能给你那么多难得的天赋”。除肖邦外，他还擅长演奏从巴洛克到浪漫派的作品，从斯卡拉蒂到莫扎特、舒伯特、德彪西都在他的表演范围。他几十年如一日坚持每天练琴10小时以上，影响了一代中国音乐人。他深厚的中国文学修养，使他能将中西文化融会贯通，用东方文化诠释西方音乐。他与父亲傅雷之间的通信被整理为《傅雷家书》，影响了几代中国人。
