# 王江民

- 姓名：王江民
- 性别：男
- 国籍：中国
- 出生日期：1951年10月7日
- 去世日期：2010年4月4日
- 去世原因：突发心脏病

# 生平简介

王江民，出生于上海，中国著名计算机反病毒专家、企业家。三岁时患小儿麻痹症，导致终身残疾。1971年参加工作，1989年开始研究计算机病毒。1996年创办北京江民新科技术有限公司，推出"KV300"杀毒软件，成为中国最早的杀毒软件之一。他被誉为"中国杀毒软件之父"。2010年4月4日因心脏病突发逝世，享年59岁。

# 主要贡献

王江民是中国计算机反病毒领域的开拓者，KV系列杀毒软件开创了中国自主研发杀毒软件的先河。他的技术创新推动了中国计算机安全产业的发展。他身残志坚，凭借不懈努力取得了巨大成就，成为青年创业者的榜样。
