# 于朦胧

- 姓名：于朦胧
- 性别：男
- 国籍：中国
- 出生日期：1988年6月15日
- 去世日期：2025年9月11日

# 生平事迹

于朦胧是中国内地男演员、歌手。2013年参加《快乐男声》获全国第十名出道。2015年因出演《太子妃升职记》中九王一角受到关注。随后参演《三生三世十里桃花》《新白娘子传奇》等热门电视剧。2025年9月11日在北京坠楼身故，警方排除刑事嫌疑。

# 主要贡献

主演《太子妃升职记》《三生三世十里桃花》《新白娘子传奇》《轩辕剑之汉之云》等电视剧；发行个人单曲《刚好》《无罪》等；2016年获"年度最具网络影响力艺人"奖。
