# 程开甲

- 姓名：程开甲
- 性别：男
- 国籍：中国
- 出生日期：1918年8月3日
- 去世日期：2018年11月17日

# 生平简介

程开甲，江苏吴江人，著名理论物理学家，中国科学院院士，"两弹一星"功勋奖章获得者，国家最高科学技术奖获得者，"八一勋章"获得者。1941年毕业于浙江大学物理系，1948年获英国爱丁堡大学博士学位。1950年回国，先后在浙江大学、南京大学任教。1960年投身核武器研制，参与中国第一颗原子弹、氢弹的研制工作，是中国核试验科学技术体系的创建者之一。2018年11月17日在北京逝世，享年101岁。

# 主要贡献

程开甲被誉为"中国核司令"，是中国核武器事业的开拓者之一。他领导建立了中国核试验科学技术体系，成功组织指挥了44次核试验，为中国核武器发展做出了重大贡献。他提出了核爆炸理论模型，解决了核试验中的关键技术问题。他曾获"两弹一星"功勋奖章、国家最高科学技术奖、"八一勋章"等多项荣誉。他隐姓埋名几十年，将毕生精力奉献给中国的国防事业，是当之无愧的民族英雄。
