# 生平简介

邵逸夫，原名邵仁楞，出生于浙江宁波，香港著名影视企业家、慈善家。1925年与兄长在上海创办天一影片公司，1930年赴香港发展。1957年成立邵氏兄弟（香港）有限公司，建立邵氏影城，制作了《江山美人》《貂蝉》《梁山伯与祝英台》等经典影片。他还创办了TVB，推动香港电视业发展。他一生致力于慈善事业，捐款超过100亿港元，用于教育、医疗等领域。2014年1月7日在香港逝世，享年107岁。

# 主要贡献

邵逸夫是香港影视业的开拓者，被誉为"香港电影之父"。他建立的邵氏影城是香港电影业的重要基地，培养了大批电影人才。他创办的TVB成为香港最大的电视台，影响了几代香港人。他的慈善事业遍及全国，捐建了大量教学楼、医院等设施。他获得过香港特别行政区政府颁发的"大紫荆勋章"，是华人世界的传奇人物。
