# 黄旭华

- 姓名：黄旭华
- 性别：男
- 国籍：中国
- 出生日期：1926年3月12日
- 去世日期：2025年2月6日

# 生平简介

黄旭华是中国工程院院士，共和国勋章获得者，中国第一代核潜艇工程总设计师。他为中国核潜艇事业隐姓埋名30年，主持设计了中国第一代攻击型核潜艇和战略导弹核潜艇。1988年在深潜试验中，随艇深潜到极限，创世界首例。他先后向科研、科普机构及各类学校捐款逾2000万元。2025年2月6日在湖北武汉逝世。

# 主要贡献

主持设计中国第一代攻击型核潜艇和战略导弹核潜艇；1988年随艇深潜到极限，创世界首例；2019年获"共和国勋章"；获国家最高科学技术奖、国家科学技术进步奖特等奖；被评为全国道德模范、感动中国年度人物。
