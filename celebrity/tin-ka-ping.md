# 田家炳

![](../pics/tin-ka-ping.jpg)

- 姓名：田家炳
- 性别：男
- 国籍：中国（香港）
- 出生日期：1919年11月20日
- 去世日期：2018年7月10日
- 去世原因：自然衰老

# 生平简介

田家炳，广东大埔人，香港著名实业家、慈善家。早年创业致富，后倾力捐助教育。2018年7月10日在香港逝世，享年99岁。

# 主要贡献

捐资创办"田家炳中学"等数百所学校，被誉为"百校之父"，获评"感动香港"人物。
