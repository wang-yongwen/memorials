# 生平简介

奥利维亚·德哈维兰（Olivia de Havilland）出生于日本东京，是美国影视女演员。1935年进入电影界，与埃罗尔·弗林合作了《侠盗罗宾汉》等多部经典影片。1939年在《乱世佳人》中扮演梅兰妮一角，让她获得奥斯卡最佳女配角提名并名声大振。1946年凭借《风流种子》获得奥斯卡最佳女主角奖，1949年又凭借《女继承人》第二次获得奥斯卡最佳女主角奖。她还出演了《深闺梦里人》《断肠花》等影片。1950年代后移居法国巴黎，逐渐淡出影坛，偶尔客串演出。2016年以百岁高龄参与纪录片拍摄，讲述好莱坞黄金时代的故事。2020年在法国巴黎家中安详去世，享年104岁。

# 主要贡献

奥利维亚·德哈维兰是好莱坞黄金时代最优秀的女演员之一，两次获得奥斯卡最佳女主角奖，多次获得提名。她塑造的梅兰妮形象温婉善良，成为《乱世佳人》中最受喜爱的角色之一。她不仅演技精湛，还为演员权利斗争做出了重要贡献——1940年代她起诉华纳兄弟公司，最终赢得官司，这一案例改变了好莱坞的演员合同制度，被称为“德哈维兰法案”。她是最后一位幸存的《乱世佳人》主要演员，见证了近一个世纪的电影史，也是最长寿的奥斯卡得主之一。她的表演优雅、细腻、富有层次，展现了女性角色的复杂性和深度。
